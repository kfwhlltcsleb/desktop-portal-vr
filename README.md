## Overview

Desktop Portal VR creates a configurable virtual monitor inside SteamVR that mirrors or extends your Windows desktop, enabling full PC usage — including flat games — from inside a VR headset.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Desktop Portal VR** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Virtual Monitor** | Configurable resolution and curvature virtual screen in SteamVR |
| **Multi-Window** | Pin multiple application windows as independent floating panels |
| **Passthrough Blend** | Mix VR passthrough with the virtual desktop for a mixed-reality feel |
| **Controller Input** | Map VR controller touchpad and buttons to mouse and keyboard events |
